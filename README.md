# 隱碼防偽 · 掃碼驗證示範站

實體防偽標籤掃碼後落地的驗證頁**概念驗證示範站**。
標籤外觀是一顆普通 QR，防偽訊號藏在碼面模塊的色彩微差裡；本頁用手機相機拍攝標籤、量測隱碼是否存活，依結果決定是否顯示產品資料。

## 驗證流程（兩段式）

**第 1 步**　手機原生相機掃碼 → 落地本頁 → 解開短碼、驗序號簽章。不過即停止。
**第 2 步**　顯示「第 2 步：拍攝標籤」，由使用者按鈕開啟相機（避免一載入就跳權限詢問）→ 定位 QR → 四角透視校正 → 逐模塊取樣 → 量測隱碼。

兩關全過才解鎖產品資料。

## 判定方式

碼面切成 4×4 格，四層隱碼共 64 格，每格各自計算「A 組平均 − B 組平均」。

**主指標是「符號一致率」**——印刷與光線變異會改變訊號的**強度**，但不會改變**符號**；
而複製品的隱碼被抹除後只能亂猜，符號正確率的期望值就是 50%。

- 一致率 ≥95%（且訊號強度過最低底線）→ **PASS**
- 一致率 ≥85% 且強度達標 → **PASS**
- 一致率 ≤65% → **FAIL**
- 其餘 → **HOLD**（建議重拍）

頁面底部「量測明細與門檻校定」可查看各層格數並現場調整門檻（存於本機瀏覽器）。
